# 🎮 Tic Tac Toe Game (Python GUI)

An interactive **Tic Tac Toe game** built using **Python and Tkinter**, featuring a fullscreen interface, bold UI design, score tracking, and a best-of-three match system.

---

## 🚀 Features

* 🖥️ Fullscreen graphical interface
* 🎨 Modern and bold UI design
* ❌⭕ Two-player gameplay
* 🏆 Best-of-3 match system (first to 2 wins)
* 📊 Real-time score tracking
* 🟢 Highlight winning moves
* 🎉 Fullscreen winner celebration screen
* 🔁 Restart option for continuous gameplay

---

## 🛠️ Technologies Used

* **Python 3.11**
* **Tkinter** (built-in GUI library)

## ▶️ How to Run

1. Clone the repository:

```
git clone https://github.com/your-username/tic-tac-toe-python-gui.git
```

2. Navigate into the project folder:

```
cd tic-tac-toe-python-gui
```

3. Run the game:

```
python3 main.py
```

## 🎯 Project Overview

This project is a GUI-based implementation of the classic Tic Tac Toe game. It demonstrates the use of **event-driven programming**, **game logic implementation**, and **user interface design** using Python. The game includes advanced features like score tracking and a tournament-style best-of-three system to enhance user experience.
